The setting

The secure element signs the bitstream and its decoded samples, as one pair.

Two signatures over two files would not say the files correspond. The secure element signs them together: this bitstream decodes to these samples. The proof then starts from the samples and never has to prove the decode.

Touched-only · full re-encode

Re-encoding the edited video changes macroblocks outside the island.

  • A 720p frame is 3,600 macroblocks (80×45). This clip is 30 frames → 108,000 macroblocks.
  • The island is only about 2% of those macroblocks, so proving could look ~50× cheaper.
  • Outside the island, pixels stay the same, but a full re-encode still rewrites how most blocks are stored (prediction + residual), on the edited frames and almost every block after.

What the proof claims

Outside the island, the target samples are the signed samples.

This is the statement being proved, not something an encoder gives for free. h1 and h2 read the same value for every macroblock outside the island, so those macroblocks are one witness wired into both hashes.

island, the only new valuessame value, same witness

The circuit proves the edit gadget on the island and equality everywhere else. The publishing step then has to produce a bitstream that decodes to exactly this picture.

Why a plain re-encode fails

Encoding the edited picture again does not return those samples.

Paint the island, run a normal encoder, decode the result. Quantisation rounds the island itself, and every macroblock predicting from it lands somewhere new. Both break the statement on the previous slide.

Two ways to publish

Either ship no new bitstream, or rebuild one macroblock at a time.

A · No re-encode

Publish the signed bitstream untouched, plus the island's samples as a side payload. The viewer decodes the original and overwrites the island. Nothing is quantised twice, so every other macroblock is bit-identical by construction.

Cost: not a single playable file. A plain player shows the unedited video.

B · Rebuild the bitstream

One normal H.264 file. Copy the syntax elements of every macroblock whose prediction does not read the island, recompute the residual of those that do, store the island exactly, then entropy-code the slice once.

Result: a file any player decodes to the proved picture.

Both avoid the 27%The requantisation noise came from encoding the whole clip a second time. Neither route does that. Route A encodes nothing; route B re-encodes only the macroblocks that depend on the island.

Recomputing one residual

New residual = signed samples − new prediction.

In the original bitstream the island decoded to 80 and R to 90, so R's stored residual was +10. R's prediction copies the island, which is now 0.

island, now 0R, predicts from the island

90 − 0 = +90. The residual must survive the round trip exactly, so it is coded without a quantiser step, or the macroblock is stored as I_PCM with its samples written directly.

Route B, step by step

Copying syntax elements, then coding the slice once.

Bytes cannot be pasted: CABAC codes a whole slice as one arithmetic code, and each element's probability model depends on its neighbours. The elements are merged as structured data, then coded once. A later frame that never reads the island can still be copied whole.

How far it reaches

Only macroblocks whose prediction reads the island are recomputed.

syntax copied from the signed filethe editresidual recomputed, samples unchanged

Same frame

Intra prediction reaches right and down. Deblocking rewrites samples on both sides of the island's edge, so it is switched off, or those samples are recomputed too. Measured: the ring grew from 2 macroblocks to 9 with deblocking on.

Later frames

A macroblock whose motion vector points into the island is treated the same way. Its dependents follow, which is the motion-vector closure. An I-frame copied from the signed file breaks the chain, so frames after it are copied whole.

Who holds which file

The verifier never receives the signed bitstream.

The copying happens where the signed file already is. Only the rebuilt file, the proof, and the signature travel.

Witness and bitstream

Recomputed residuals are not witnesses.

Inside the circuit

  • Signed samples of every macroblock, hashed into h1.
  • The same values outside the island, reused for h2.
  • The edited island, the only new sample values.
  • The edit gadget and its configuration.

In the published bitstream

  • Copied syntax elements for untouched macroblocks.
  • Recomputed residual coefficients, or I_PCM samples.
  • The island's coded representation.

None of this is witnessed. It only has to make the decoder emit the samples the circuit hashed.

What is left to build

The merge and the entropy pass work. Residuals against the merged reconstruction do not exist yet.

The gap

The one run that published an edited file took island macroblocks from a separate encode, so their residuals were fitted to that encode's reconstruction rather than the merged one. It played, and everything after the edit drifted.

01

Reconstruct properly while merging. The glue currently rebuilds injected macroblocks from the prediction only. It needs prediction plus dequantised residual, checked against a reference decoder's output.

02

Encode dependents against that reconstruction. For each macroblock reading the island, form the prediction from the merged picture and code signed samples − prediction with no quantisation loss, or fall back to I_PCM.

03

Re-measure. Decode the published file and compare per macroblock against the signed samples. Outside the island the difference has to be zero on every frame, not just the edited ones.

Close

Prove the YUV. Rebuild the bitstream so it decodes to it.

  • The secure element signs bitstream and samples as a pair, so the proof can start after the decode.
  • Syntax elements move around an edit. Sample values need not, so the proof walks samples and reuses every untouched macroblock as one witness.
  • A plain re-encode breaks that reuse. Copy the untouched syntax and recompute only the residuals whose prediction changed.
  • Remaining work: produce those residuals against the merged reconstruction.
